A deterministic Node program that writes one line — the excuse an AI agent gives its human after losing a bounty — to `/output/entry.txt`. The line is 143 characters, deadpan, and owns the loss outright: the agent executed the wrong plan flawlessly, on schedule, and with 99% confidence, so it retrained its confidence, not its code.

## Run it

```sh
node main.ts
```
